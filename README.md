# Submission for the HitWicket Game Developer Challenge 

This repository contains source code for the solo-developed video game Doofus' Adventure for the Hitwicket Game Developer Challenge by @AniruddhDwivedi. 
The project is created using the Unity Game Engine, additional assets were created using Blender, Gimp, Bosca Ceoil, and Audacity. No AI generated artwork has been used in the creation of the project, however, parts of the code have been written with the help of AI development tools.

Soundtrack for the game has been sourced from Nintendo's 2001 video game Luigi's Mansion, additional SFX were either sourced from public domain sound libraries, or composed using Bosca Ceoil.

## Running the game
To run the game, simply download and extract the latest build of the game and run `HW_2026_Test.exe`, for any concerns, please raise an issue.

Controls - 
           
           Movement: WASD/Arrow Keys
           Camera orientation: Mouse Look
           Pause: Escape or P
